# История изменений

## Не выпущено

- Исправлено подключение Windows named pipe через go-winio v0.6.2; транспорт поддерживает отмену и бюджет ручных операций 20 секунд.

- Добавлены логи выбранного контейнера и действия запуска/перезапуска/остановки schema2 с ограничением времени и явным неизвестным исходом. Поведение сборщика schema1 сохранено; добавлены ID и отдельный совместимый пакет v1.

## 1.0.3

### Добавлено

- Маркер обнаружения для Pulse Marketplace; файл включён в архив исходников.
- Поведение нативного сборщика и протокол установки schema-1 сохранены. Обнаружение не означает одобрения: публикация в marketplace требует независимой модерации.

## 1.0.2

### Исправлено

- CPU рассчитывается по двум текущим замерам с интервалом в одну секунду вместо отношения накопленных счётчиков за всё время.
- Если метрики работающего контейнера недоступны, суммы остаются неизвестными вместо отображения неполного результата.

## 1.0.1

### Добавлено

- Самостоятельный репозиторий, лицензия MIT, инструкции сборки и установки.
- JSON-пакет для Linux amd64/arm64 и Windows amd64, исходный архив и контрольные суммы SHA-256.

### Исправлено

- Подключения к Windows Docker named pipe используют асинхронные дескрипторы и повторяют попытку при занятом канале в пределах срока запроса.

### Примечания

- Модуль сохраняет `id: docker`, `schemaVersion: 1`, `protocol: 1` и использует независимую версию пакета.
- Первый публичный набор: Pulse Monitor v0.4.0, Pulse Agent v0.4.0 и Docker-модуль v1.0.1.
- v1.0.1 обозначает новое содержимое пакета; установленная v1.0.0 остаётся неизменной.

## 1.0.0

### Добавлено

- Исходный Docker-сборщик: версия движка, контейнеры, ресурсные показатели, сетевые счётчики и необязательные последние журналы контейнера.
- Нативный процесс с JSON stdin/stdout для протокола модулей v1. Пакет предшествовал самостоятельному репозиторию.
