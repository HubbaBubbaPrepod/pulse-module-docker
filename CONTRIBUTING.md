# Участие в разработке

Go 1.23+; для создания пакета — PowerShell 7.4+. Из корня:

```powershell
go build ./...
go test ./...
go vet ./...
./scripts/build.ps1 -Version 1.0.1
```

Проверка сборки для платформы не подтверждает работу на этой ОС. Для runtime-проверки нужны работающий Docker Engine и доступ к Unix socket либо Windows named pipe. При отчёте о проверке укажите ОС, архитектуру, версию Docker и права учётной записи. Не заявляйте проверку на недоступной платформе.

В PR опишите проблему, минимальные изменения, выполненные проверки и ограничения. Изменения полей, представлений или протокола согласуйте с панелью и агентом; обновите манифест и changelog. Бинарные изменения публикуйте под новой версией — существующий пакет/тег не переписывайте. Коммиты: `type(scope): summary`, до 72 символов.

Не прикладывайте реальные credentials или чувствительные журналы контейнеров в публичные Issues. Вклад распространяется под [MIT](LICENSE).
